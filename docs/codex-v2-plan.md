### 3.2 关卡选择界面



* 新场景字符串 `"level_select"`，从开始界面新增 "选择关卡" 按钮进入。

* 界面：3 行 2 列的卡片网格，每张卡片显示：


  * 关卡序号 + 名称；

  * 该关最佳星级（★★★ / ★★☆ / ★☆☆）；未通关显示空星；

  * 锁定关显示锁图标和 "通关上一关解锁"。

* 点击已解锁关卡 → 直接进入 `playing`。

* 顶部加 "返回" 按钮回到开始界面。

* 进入 `playing` 时必须重置该关的计时器、撤销计数、提示计数。

### 3.3 计分、计时、星级

**计时器**



* 进入 `playing` 时开始计时；动画期间和结果浮层显示时**暂停**计时。

* 结果页显示用时（秒，保留 1 位小数）。

**分数（每次成功消除一个箭头即时累加）**



* 基础分：每个箭头成功飞出 `+100`。

* 失误惩罚：每次被阻挡 `-50`（不会扣到负数）。

* 时间奖励：通关时按本关预算秒数计算，`max(0, round((预算秒数 - 实际秒数) * 5))`。

* 预算秒数建议：每关箭头数 × 4 秒（L4=48s, L5=56s, L6=64s；前三关沿用现有体验，可分别设为 32/48/64）。

* HUD 右侧实时显示当前分数。

**星级（1–3，按通关时剩余机会判定）**



* 3 星：通关时 0 次失误。

* 2 星：通关时 1 次失误。

* 1 星：通关时 ≥2 次失误（或 L6 这种 2 命关扣到 1 次）。

* 使用过提示：星级**强制封顶 2 星**（哪怕 0 失误也只给 2 星）。

* 结果页用大星星显示本次星级；关卡选择页显示历史最佳。

### 3.4 提示功能



* HUD 新增灯泡按钮，或按 `H` 键。

* 每关 1 次机会；用完后按钮变灰。

* 触发时：调用 `solve_board(当前棋盘)` 找到**当前任意一个可立即飞出**的箭头，给它加一个 1.5 秒的脉动光环（颜色与箭头同色，外圈呼吸），不自动点它，只做视觉提示。

* 提示不扣命，但按 §3.3 封顶星级。

* 提示期间动画锁定（不接受棋盘点击），1.5 秒后恢复。

### 3.5 撤销上一步



* 撤销对象：**只撤销成功的 CLEARED 动作**（箭头飞出）。被阻挡的 BLOCKED 动作不能撤销（那是失误，重开本关是唯一恢复方式）。

* 每关最多撤销 3 次；HUD 显示剩余撤销次数（用小箭头图标）。

* 撤销时：

1. 把上一次飞出的箭头放回原位（方向、坐标都恢复）；

2. 分数回退 `+100`；

3. 不恢复 "使用过提示" 的标记；

4. 撤销本身**不扣命、不扣分**（除了回退那 100 分）。

* 快捷键 `U`；动画期间禁用。

* 实现建议：在 `GameState` 里维护一个轻量栈 `undo_stack: list[tuple[int,int,str]]`（坐标 + 方向），每次 CLEARED 时 push；undo 时 pop 并把格子写回。**保持&#x20;**`game_logic.py`**&#x20;不 import pygame**。

### 3.6 存档



* 文件：`save.json`，放在**可执行文件 / 脚本所在目录**（用 `Path(__file__).resolve().parent / "save.json"`，不要写到 temp）。

* 格式：



```
{

&#x20; "unlocked\_level": 3,

&#x20; "muted": false,

&#x20; "best": {

&#x20;   "0": {"stars": 3, "best\_time\_sec": 12.4, "best\_score": 520},

&#x20;   "1": {"stars": 2, "best\_time\_sec": 31.0, "best\_score": 480}

&#x20; }

}
```



* `unlocked_level` 是已解锁到的最大下标（0-based）；首次运行默认 `0`。

* 通关第 N 关时：把 `unlocked_level` 提升到 `max(unlocked_level, N+1)`（不超过 5）。

* 每次结果页出现、切换静音、返回开始界面时自动保存。

* 读档容错：文件不存在或 JSON 损坏时回退到默认存档，不崩溃。

### 3.7 程序化音效（零素材）

新建 `audio.py`，用 `numpy` 在运行时合成 PCM，再交给 `pygame.mixer.Sound(buffer=...)`。**不落地任何 wav 文件**。

初始化（在 `pygame.init()` **之前**）：



```
pygame.mixer.pre\_init(44100, -16, 2, 512)
```

音效清单（采样率 44100，16-bit 立体声）：



| 名称          | 触发时机 | 合成方式                                                     | 时长    |
| ----------- | ---- | -------------------------------------------------------- | ----- |
| `fly`       | 箭头飞出 | 正弦音高随时间指数滑动；U = 音高上升，D = 下降，L/R 做左右声道偏移（pan=-0.8 / +0.8） | 0.25s |
| `blocked`   | 被阻挡  | 短白噪声爆发 + 120Hz 正弦，快起音快衰减                                 | 0.15s |
| `click`     | 按钮点击 | 800Hz 正弦，0.05s                                           | 0.05s |
| `clear`     | 本关通关 | C5-E5-G5 三个正弦音依次拼接，每个 0.12s                              | 0.4s  |
| `game_over` | 失败   | G4→D4 两音下行                                               | 0.5s  |
| `all_clear` | 全部通关 | 简短号角：C5-E5-G5-C6 琶音 + 尾音                                 | 0.8s  |

`AudioManager` 接口：



```
class AudioManager:

&#x20;   def play(self, name: str, pan: float = 0.0) -> None: ...

&#x20;   def set\_muted(self, muted: bool) -> None: ...

&#x20;   def set\_volume(self, v: float) -> None: ...  # 0.0–1.0
```



* `M` 键切换静音，HUD 右上角画一个喇叭图标（开 / 叉两种状态）。

* 静音状态写入 `save.json`。

* `requirements.txt` 增加 `numpy>=1.26`。

* 注意：连点去重 —— 动画进行中不重复播 `fly`（现有逻辑已在动画期间忽略输入，直接复用）。

### 3.8 更顺滑的动画

在现有动画基础上做加法，不要重做：



* **飞行动画**：除了现有飞出箭头，在身后叠 2 个半透明 "残影"（偏移 6px / 12px，alpha 递减），让它有运动拖尾。

* **被阻挡动画**：除了现有抖动，在箭头位置向外爆 5 个小圆点粒子（DANGER 色，向外飞 12px 后消失）。

* **关卡入场**：新关加载时，箭头不要一次性出现，按从左上到右下顺序每个间隔 30ms 依次 "弹出"（scale 从 0.6 弹到 1.0，100ms 完成）。

* **结果浮层**：现在是瞬间弹出，改成 0.2s 淡入（alpha 从 0 → 255）。

* 所有动画总时长仍控制在 0.6s 以内，保证点击节奏不拖。
